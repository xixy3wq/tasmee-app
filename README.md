# حلقات ارتق — منصة حلقات التسميع عن بُعد

تطبيق ويب عربي مبني بـ **Next.js 14 + Prisma + PostgreSQL (Neon)**، يُرفع على **Vercel** بنفس طريقة منصة الحلقة التربوية.

## الأدوار

| | المدير | المعلم | الطالب وولي الأمر |
|---|---|---|---|
| طلبات التسجيل والاعتماد | ✓ | — | يسجّل عبر الرابط |
| الحلقات وأيام الدوام والمعلمين | ✓ | — | — |
| الحصص (رابط لكل حصة) | كل الحلقات | حلقاته | زر «ادخل الحصة» |
| التحضير (حاضر/متأخر/غائب/مستأذن) | ✓ | ✓ | يرى حضوره |
| طابور التسميع وتسجيل التسميع | ✓ | ✓ | يرى سجله |
| الخطة (يدوية / تلقائية) | ✓ | بصلاحية من المدير | يرى المطلوب منه |
| رسائل واتساب لولي الأمر | ✓ | ✓ | — |
| الإعدادات: حقول التسجيل، سلّم التقدير، نص الرسائل | ✓ | — | — |

ولي الأمر يدخل بحساب ابنه.

## الرفع على الإنترنت (مرة واحدة)

1. **GitHub**: أنشئ مستودعًا جديدًا باسم `tasmee-app` وارفع فيه ملفات هذا المجلد.
2. **Vercel**: Add New → Project ← اختر المستودع `tasmee-app`.
3. **قاعدة البيانات**: من صفحة المشروع في Vercel ← Storage ← Create Database ← **Neon** ← اربطها بالمشروع. يضيف Vercel تلقائيًا `DATABASE_URL` و `DATABASE_URL_UNPOOLED`.
4. **المتغيرات** (Settings → Environment Variables):
   - `AUTH_SECRET` = نص عشوائي طويل (32 حرفًا أو أكثر)
   - `SEED_ADMIN_USERNAME` = اسم مستخدم المدير (حروف إنجليزية صغيرة)
   - `SEED_ADMIN_PASSWORD` = كلمة مرور المدير (8 أحرف أو أكثر)
   - `SEED_ADMIN_NAME` = اسمك (اختياري)
5. **Deploy** (أو Redeploy بعد إضافة المتغيرات). الجداول وحساب المدير تنشأ تلقائيًا مع كل رفع.

> نسيت كلمة مرور المدير؟ أضف `SEED_ADMIN_FORCE_PASSWORD=1` واعمل Redeploy، ثم احذف المتغير.

## أول استخدام

1. ادخل بحساب المدير.
2. **الإعدادات**: اسم الحلقات، أيام الدوام، سلّم التقدير، حقول التسجيل، ونص رسائل واتساب.
3. **المعلمون**: أضف المعلمين وحدد صلاحياتهم (إعداد الخطط / الخطة التلقائية).
4. **الحلقات**: أنشئ الحلقات وأسند لكل حلقة معلمها، وانسخ **رابط التسجيل** لكل حلقة وأرسله للطلاب.
5. **الطلبات**: اعتمد الطلاب. من صفحة كل طالب تقدر تسمح له بالخطة التلقائية.

## الخطة التلقائية

- المعلم يحدد الاتجاه (من الناس أو من الفاتحة) وموضع البداية، ومقدار الحفظ والمراجعة والتثبيت اليومي بالأوجه.
- تتقدم الخطة فقط إذا سمّع الطالب ونجح (أي تقدير غير «يعاد»). إذا غاب أو أعاد يبقى نفس المقطع.
- الأوجه محسوبة على مصحف المدينة (604 صفحات) من مكتبة `quran-meta`.

## هيكل المشروع

```
prisma/schema.prisma      ← الجداول: User, Halqa, Lesson, Join, Rec, Setting

lib/                      ← الجلسات، الصلاحيات، بيانات المصحف، الإعدادات
app/api/login|logout|register|data|act|pages
public/app.js             ← الواجهة كاملة
app/globals.css           ← التصميم (فاتح وداكن)
```
